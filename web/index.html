Audio + SRT

Select the exact recording matching the subtitle timestamps. UTF-8 SubRip (.srt), up to 5 MB.

Import moves this recording's old clips and caches to Trash, then cuts audio using the subtitle timestamps. New clips start disabled. Review and enable them manually, or run the STT check. Mismatches stay disabled. Word agreement does not prove timing or speaker identity. Your supplied text is never overwritten.

GPUs

Training with several GPUs runs one process per card and averages adapter gradients after every update (NCCL). Each card holds a full model copy in its own 24 GB (or smaller) memory; cards do not form one shared memory pool. STT, subtitle checks, feature encoding and generation use one GPU. Utilization varies with batch size and data loading; constant 100% is not expected.
